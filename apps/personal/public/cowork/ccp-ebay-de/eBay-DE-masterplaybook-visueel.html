Allow Countries — root cause DE-orders Magentojij zet DE erbij
Duitse eBay-orders faalden op import (platform_failure); NL-orders (bol) importeerden wél.
Oorzaak (live geverifieerd): Allow Countries = alleen NL; op de storeview "Duits" staat Default Country wél op DE → mismatch.
Fix (zelf, veilig): Stores → Configuration → General → Country Options → Allow Countries → Duitsland toevoegen (NL behouden) → Save. Daarna Channable "verzend mislukte orders opnieuw".
DE storeview-incident Magentobesluit
Storeview "Duits" staat nog Enabled — niet verwijderd, niet uitgezet. Het bestaan ervan blokkeert de orders niet.
Besluit: eBay DE live zonder DE storeview — 1 omgeving voor alle orders. Storeview geparkeerd (disable), niet verwijderen.
