1Track & Trace automatiseren

DPD-tracking moet automatisch in het eBay DE-account. Keten: ABS API → generieke Magento-velden (Niek, in bouw) → Magento → Channable auto-update → Channable → marketplace (order-sync "Complete", tracking terug). Stappen 2-3 nog niet bevestigd werkend — dat is het gat.

Meedenken Channable-kant · evt. bij Niek-meeting di 11:00-11:30
2Image tool — main images

Main images lijken vierkant maar worden niet zo geëxporteerd. Voor Magento geen probleem, marketplaces eisen minimale afmetingen (rond 500×500). Met de Channable image tool alle main images bij export op de eis krijgen.
