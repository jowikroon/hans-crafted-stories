Retourflow DE→NL — stap voor stap (vervolg)

CCP · features activeren, carrier + retouradres, landroutering, test
4
In Returnless: features aanzetten op het retourformulier
Returnless → Settings → Return forms → formulier openen → tab Integrations
Return form (eBay DE) → tab Integrations
Channable ▾ ◉ kies
Channable-sectie — zet aan:
Search order (koper vindt order via ordernummer + e-mail/postcode)
Return importer (retouren uit Channable ophalen, elk uur)
Finalize return (retour "accepted" → Channable start refund)
Save ◉ klik
Voor eBay DE (eigen retourformulier) is Search order + Finalize return het belangrijkst. Return importer gebruik je alleen als het kanaal retouren in Channable aanmaakt (vooral bol).
5
In Returnless: carrier + NL-retouradres instellen
Returnless → Shipping / Carriers → carrier toevoegen
DPD ▾ (of DHL Paket Retoure)
Eigen DPD-contract ▾ of tarief van Returnless
ABS NL-magazijn, Nederland
Je gebruikt DPD al voor uitgaande DACH-zendingen, dus DPD DE→NL sluit direct aan.
6
In Returnless: label routeren per land
Returnless → Return rules / Shipping → regel per land
Regel: Als land koper = Duitsland (DE) dan label = DPD DE → NL
Regel: Als land koper = Nederland (NL) dan label = PostNL / DPD NL
Auto-routing: Duitse koper krijgt automatisch een Duits label naar het NL-magazijn, geen handwerk.
7
Testen: maak een testretour en controleer het label
Returnless → retourformulier (testmodus) → testorder eBay DE
Doorloop het retourformulier met een eBay DE-testorder. Controleer:
✓ order wordt gevonden via Channable  ✓ label = Duits ophaalpunt → NL-adres  ✓ na "mark as received" volgt refund + sync
Let op (testmodus): de Return importer draait niet in testmodus. Test de eigen-formulier-flow (model B) los.
