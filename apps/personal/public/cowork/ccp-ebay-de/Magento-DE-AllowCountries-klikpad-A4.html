Duitsland toevoegen aan Allow Countries — Magento

CCP × A.B.S. · eBay DE go-live · 5 klikken in Magento + 1 in Channable · veilig & omkeerbaar · Atvise niet nodig
Waarom: Duitse eBay-orders worden geweigerd op import omdat Allow Countries op alléén NL staat (Default Country DE staat al goed op de storeview "Duits"). Deze wijziging zet DE erbij.
Geverifieerd live in de Magento-config, 2026-07-09.
1
Open het Stores-menu (linkerbalk) → klik Configuration
DASHBOARD
SALES
CATALOG
STORES ●SYSTEM
Settings
All Stores
Configuration ◉ klik hier
Terms and Conditions
2
Zet de scope linksboven op Default Config
Store View: Default Config ▾ (niet "Duits" — juist de standaard/globale scope)
3
Tab General → klap Country Options open
Locale Options
Country Options ◉ open deze sectie
State Options
4
Bij Allow Countries: houd Ctrl ingedrukt en klik Germany erbij
Allow Countries
France
Belgium
Germany ◉ Ctrl+klik
Netherlands (al geselecteerd — laten staan)
Austria (optioneel, DACH)
Poland
Let op: NL niet deselecteren. Ctrl vasthouden = DE erbij, niet vervangen.
5
Klik Save Config rechtsboven — cache legen indien gevraagd
Save Config ◉ klik
6
In Channable → Orders → "Verzend alle mislukte orders opnieuw"
De Duitse orders importeren nu wél → krijgen een Magento-ID → shipment + T&T volgt → terugkoppeling naar eBay komt op gang.
