3 · Retourformulier koppelen (live bevestigen)

Waar: Instellingen → Retourformulieren → open het formulier → tab Integraties. Er is nu één formulier: "Retourformulier".
  • Default search integration op het eBay DE-formulier = Channable - CCP eBay DE. Hiermee wordt "Search order" actief voor dit formulier.
  • Zet aan: Finalize return (retour "accepted" in Channable → refund via eBay).
  • Keuze: gebruik hiervoor bij voorkeur een apart formulier voor eBay DE (Duitse taal, DE→NL label), zodat de bestaande webshop-"Retourformulier" op Magento blijft staan. Eén formulier kan maar één default search integration hebben.
  • Let op (doc-bevestigd): Channable levert geen productafbeeldingen via de API → in dit formulier zie je geen productfoto's. Functioneel geen probleem.

4 · Carrier / retourlabel DE→NL (live bevestigen)

Waar: Instellingen → Verzendcontracten. PostNL draait al voor NL-retouren.
  • Voeg DPD (of DHL Paket Retoure) toe voor DE→NL als die er nog niet is. Eigen DPD-tarief of dat van Returnless.
  • Retouradres (bestemming) = ABS NL-magazijn.
  • Landregel op het eBay DE-formulier: Duitse koper → DPD DE-label naar NL; NL-koper → PostNL.

5 · Opruimen — Magento 2 - Development

Doen: verwijder of ontkoppel de integratie Magento 2 - Development als order-bron. Dit is de secundaire koppeling die 82x faalde ("could not fetch sales order: Development"). Zo draaien order-lookups alleen op Production en verdwijnen de valse fouten. Bevestig eerst dat hij niet als default search op een actief formulier staat.

6 · Harde voorwaarde — buiten Returnless

De eBay DE-order moet eerst schoon in Magento/Channable landen. Zolang de storeview/landcode de import breekt (Allow Countries DE ontbreekt, land als naam i.p.v. ISO), staat de order niet in het systeem en vindt de "Search order" hem niet. Volgorde: eerst order-import fixen (DE toestaan + ISO-landcode + storeview terug), dan pas retouren testen.

7 · Validatie (test na instellen)

  • eBay DE-testorder landt schoon in Magento (144013xxx, geen platform_failure).
  • In het eBay DE-formulier: zoek de order op via postcode → order gevonden via Channable.
  • Retour aanmaken → label = DPD DE-ophaalpunt → NL-adres (niet PostNL).
  • NL-testretour → PostNL-label (landregel werkt).
  • "Mark as received" / Finalize → refund via eBay + status-sync.
  • Instellingen → Integraties → Application logs: geen nieuwe "could not fetch sales order: Development".
