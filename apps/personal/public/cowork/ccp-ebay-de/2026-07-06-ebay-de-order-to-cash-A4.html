eBay.de — wat is écht nodig per klantorder · order-to-cash

CCP × A.B.S. · onderzoek 2026-07-06 · btw/factuur = finance/legal, laat factuurplicht + OSS-tarief door Sjoerd/adviseur bevestigen
Kern: voor de klantkant heb je Magento/ABS/DPD niet nodig om te mailen. eBay stuurt zelf de bestelbevestiging én de trackingmail (zodra het trackingnummer op de order staat). Een klantfactuur is B2C niet verplicht in DE (B2B wél). Retouren lopen eBay-managed (label + RMA) en verwerk je fysiek als webshopretour. → De Magento-DE-storefront is nodig voor onze eigen administratie/factuur, maar is geen blocker voor het correct bedienen van klanten maandag.

Klantfactuur — de Bolmate-voor-eBay

  • B2C: geen factuurplicht in DE — eBay-bevestiging volstaat.
  • B2B: factuur verplicht, binnen 6 mnd, op verzoek.
  • easybill — koppelt direct aan eBay, auto-factuur + mail (1–14 dgn), OSS/DE-tarief. Buiten Magento om.
  • Billbee — multichannel: eBay + Amazon + bol.com → één tool i.p.v. Bolmate + los eBay.
  • Review: geen losse review-spam; wel nette review-uitnodiging als tekst/bijlage bij de factuurmail.

Retouren — ja, als webshop

  • Aanvraag past bij beleid → auto-geaccepteerd.
  • Artikelwaarde ≥ €12 → eBay stuurt DHL/Hermes-retourlabel.
  • RMA = eBay-ordernummer (eigen RMA kan niet meer).
  • Te groot/zwaar (schijven >5 kg) → eigen DPD-label uploaden.
  • Pakket komt bij ons binnen → controleren + refund via eBay.
  • Instellen: retourbeleid (30 dgn), retouradres, provider, verwerker.

Gemiste randzaken — marketplace manager scope

  • Business Policies (Shipping/Payment/Return) compleet + aan álle listings gekoppeld.
  • Payout-config eBay Managed Payments: bank, schema, valuta EUR.
  • Handling time realistisch (Late-Shipment-Rate ≤3%).
  • Out-of-stock control — voorkom verkoop niet-leverbaar (5 min sync-mismatch).
  • eBay Messages reactietijd (telt mee voor serviceniveau).
  • Cases: INR (niet ontvangen) / SNAD (niet als beschreven), annuleringen, refunds — proces + eigenaar.
  • Tracking-upload-discipline — geldig trackingnr. tijdig op elke order.
  • GPSR: Responsible Person op elke listing + verpakking; check Compliance Dashboard in Seller Hub.
  • OSS: 19% DE-btw op listing + factuur (verzenden vanuit NL); DE-voorraad → apart DE-btw-nr.
  • Promoted Listings (Anzeigen) — ná content-check.
